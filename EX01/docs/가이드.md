# EX01 가이드 — Memo 예제를 회원으로 바꾸기

강사 SAMPLE 의 `07_DATASOURCE` Memo 예제와 이 과제는 **구조가 똑같다.**
Memo → Member 로 이름과 컬럼만 바꾸면 된다. 새 개념은 없다.

| Memo 예제 | 이 과제 |
|:--|:--|
| `tbl_memo(id, title, writer, text, createAt)` | `tbl_member(id, name, email, phone, createAt)` |
| `MemoDTO` | `MemberDTO` (제공됨) |
| `MemoDAO.insert / selectAll` | `MemberDAO.insert / selectAll` ← TODO |
| `MemoController(/memo)` | `MemberController(/member)` ← POST 본문 TODO |
| `templates/memo/*` | `templates/member/*` (제공됨) |

---

## STEP 0. DB 준비

`db/schema.sql` 을 MySQL `testdb` 에 실행한다. (테이블 + 시드 3건)

---

## STEP 1. MemberDAO.insert() 채우기

MemoDAO.insert 와 같은 흐름이다.

1. `dataSource3.getConnection()` 으로 Connection 을 얻는다.
2. `conn.prepareStatement("insert into tbl_member values(null,?,?,?,?)")`.
3. `pstmt.setString(1, dto.getName())`, email, phone 순으로 바인딩.
4. `pstmt.setTimestamp(4, Timestamp.valueOf(LocalDateTime.now()))`.
5. `pstmt.executeUpdate()` 결과(int)를 반환.

> `id` 는 AUTO_INCREMENT 라 `values(null, ...)` 의 첫 자리는 null 이다.

---

## STEP 2. MemberDAO.selectAll() 채우기

1. `prepareStatement("select * from tbl_member order by id desc")`.
2. `executeQuery()` 로 ResultSet 을 받는다.
3. `while(rs.next())` 안에서 `MemberDTO.builder()` 로 한 건씩 매핑:
   `.id(rs.getLong("id")).name(rs.getString("name")).email(...).phone(...)`
   `.createAt(rs.getTimestamp("createAt").toLocalDateTime()).build()`
4. List 에 add 하고 반환.

---

## STEP 3. MemberController.memberAddPost() 채우기

MemoController.memoAddPost 와 같은 흐름이다.

1. `if (bindingResult.hasErrors())` 이면
   `for (FieldError error : bindingResult.getFieldErrors())` 안에서
   `model.addAttribute(error.getField(), error.getDefaultMessage())` 후 `return "member/add";`
2. 통과하면 `memberDAO.insert(memberDTO);`
3. `redirectAttributes.addFlashAttribute("message", "회원등록 성공!");`
4. `return "redirect:/member/list";`

---

## STEP 4. 실행·확인

```
gradlew bootRun
```

- `http://localhost:8090/` → 메뉴
- `/member/add` 에서 빈 값으로 저장 → 필드별 에러 메시지 확인
- 정상 입력 → `/member/list` 로 이동, 목록 표시 확인
